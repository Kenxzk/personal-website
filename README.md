# Xiaokun (Ken) Zhong Personal Website

Static Astro site for a one-page ML researcher / research engineer profile.

## Editing Content

- Homepage copy and section data live in `src/pages/index.astro`.
- Update profile links, highlights, news, publications, experience, and selected projects in the arrays at the top of that file.
- Replace `public/resume.pdf` to update the CV link at `/resume.pdf`.
- Add optional project links later by adding items to each project's `links` array.

## Commands

```sh
npm run dev
npm run build
npm run preview
```
