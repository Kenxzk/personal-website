# Xiaokun (Ken) Zhong Personal Website

Static Astro site for a one-page researcher profile focused on optimization, model evaluation, and scientific discovery.

## Editing Content

- Homepage copy and section data live in `src/pages/index.astro`.
- Update profile links, news, publications, experience, and additional projects in the arrays at the top of that file.
- The Research section combines the published SciML feature with an explicitly labeled ongoing SciML Autoresearch project. Keep unpublished outcomes out of the project description until they are ready to share.
- Replace `public/resume.pdf` to update the CV link at `/resume.pdf`.
- Additional projects use compact text rows so the main research remains the focus.

## Commands

```sh
npm run dev
npm run build
npm run preview
```
